# 15 — Decision Log

Every major design decision behind this planning package, the alternatives
considered, and why the selected option wins. Referenced as `DL-xx` from
`02-research-thesis.md` §8 and elsewhere. Policy (from the goal): when several
plausible options exist, we analyze alternatives, document trade-offs, pick the
most ambitious _technically coherent_ option that preserves scientific validity
and testability, and record the rejected alternatives here.

| id    | decision                              | chosen                                                                                             | rejected alternatives                                                                | rationale                                                                                                                                                                                                                                                                                                                                                                                                               |
| ----- | ------------------------------------- | -------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| DL-01 | Subject model                         | One frozen, open-weight, coding-capable instruct model served locally with seed/temp control       | (a) hosted API model; (b) the local Qwen foundation subject; (c) fine-tuned subject  | Local + seed control is required for the N-sample distributional causal nulls (DL-09) and free reruns; hosted APIs forbid seed pinning and cost money per rerun. The foundation subject's only real result is a saturation plateau vs _untrained_ baselines and it has never run on real Qwen weights (audit) — off critical path. No weight training keeps us inside `training_weight: 0.0 / not_authorized`.          |
| DL-02 | Agent scaffold                        | New minimal deterministic ReAct driver OUTSIDE `src/pneuma_lab/replay/`                            | (a) reuse the replay harness; (b) adopt full OpenHands/SWE-agent                     | Replay harness drives _frozen_ trajectories and cannot run a live stochastic agent (replay + interventions audits). A heavyweight external scaffold adds uncontrolled variance and a large dependency; a minimal shared scaffold maximizes cross-condition control (the E-0 lesson).                                                                                                                                    |
| DL-03 | Conditions                            | Base, Retrieval, Reflection, Pneuma-state + Retry-count baseline + Pneuma-ablated null             | 4-condition-only (ChatGPT brief)                                                     | The retry-count controller is the falsification guard demanded by the in-repo E-0 result (psyche lost to retry-count at failure prediction, AUROC 0.34 vs 0.71). The ablated null is the H2 causal control. Both are non-negotiable for credibility.                                                                                                                                                                    |
| DL-04 | State variables                       | Four causally-active (`s_m`, `c`, `t`, `r`) + one derived `L`                                      | (a) the full 9-axis affect + 8 drives + all families (~20 vars); (b) one scalar      | ~20 hand-tuned variables invite the "arbitrary hidden prompt decoration" objection and dilute causal attribution. One scalar cannot separate failure-memory from confidence/caution/memory-trust for the per-variable ablation sweep. Four is the minimum that (i) each maps to an existing tested clamp seam and (ii) supports the differentiator ablations.                                                           |
| DL-05 | State→behaviour coupling              | Bounded decision head emitting action-shaping _pressure_ over a fixed action set                   | (a) state edits raw shell commands; (b) state only in the prompt as text             | Raw commands break the repo invariant "Pneuma emits pressure, not commands" and are unsafe/unbounded. Pure-prompt-text injection is exactly the reflection baseline — it would collapse the Pneuma-state condition into Reflection and forfeit the structured-vs-text differentiator. A deterministic head is clampable (H2) and loggable.                                                                              |
| DL-06 | Benchmark                             | Dual: synthetic controlled-motif + real-repo (Open-SWE-Traces primary, SWE-Gym-Sampled complement) | (a) synthetic only; (b) real only; (c) live agent rollouts on SWE-bench from scratch | Synthetic-only overfits and lacks external validity; real-only loses the clean motif ground-truth and deterministic oracle needed for the byte-equality causal positive-control. The dual design lets the two causal paths corroborate. Live-from-scratch rollouts on the full SWE-bench are out of budget; the on-disk trajectory corpora already carry recurring-failure structure (2 models × 2 harnesses per task). |
| DL-07 | Failure taxonomy                      | ~12 motifs with detector-computed ids                                                              | freeform LLM-labeled failures                                                        | Fixed motif ids give an objective RUF denominator and enable motif-axis holdout; freeform labels are unstable and un-splittable. N-judge ensemble bounds subjectivity.                                                                                                                                                                                                                                                  |
| DL-08 | Primary metric                        | Repeated-underlying-failure rate (RUF), post-exposure, motif-id equality                           | (a) task success / Pass@1; (b) failure count                                         | Pass@1 is what every prior SWE + memory paper already reports and does not isolate _repetition_ — our whole novelty. RUF is defined on post-exposure instances so it directly measures "stopped repeating the same mistake."                                                                                                                                                                                            |
| DL-09 | Causal validity for stochastic agents | Statistical N-sample distributional nulls + four freezes + branch-divergence                       | keep the `sha256` byte-equality clone gate                                           | Byte-equality admits only deterministic subjects and caps a real agent at Level 3 (interventions audit) — the headline experiment cannot run under it. The deterministic runner is retained _verbatim_ only for the synthetic-oracle positive control.                                                                                                                                                                  |
| DL-10 | Anti-gaming                           | Prose-blind behavioural evaluator + counterfactual tasks + decoys + N-judge + immutable traces     | trust self-report / reflection prose                                                 | The reflection literature conflates mechanism and explanation; the repo's own anti-fake-progress doctrine ("architecture is not evidence — only receipts + interventions + nulls") demands behaviour be scored independently of prose. The one-way scorer→voice firewall already exists and is verified.                                                                                                                |
| DL-11 | Self-report study                     | Secondary; four report conditions; never feeds the behavioural score                               | make faithful self-report a primary claim                                            | Introspection faithfulness (H3) strengthens but must not gate H1/H2; keeping it downstream preserves the firewall and avoids circular evaluation.                                                                                                                                                                                                                                                                       |
| DL-12 | Target venue                          | IAB @ NeurIPS 2026 (primary), Who-Verifies (secondary), both 2026-08-29                            | full NeurIPS main track; other workshops                                             | IAB's call explicitly solicits trajectory representations, error taxonomies, and methods to interpret what an agent did — a near-exact topical match; non-archival lets us extend to a full venue later. Main-track scope/timeline is wrong for a single-result methods paper.                                                                                                                                          |
| DL-13 | Consciousness framing                 | Motivation only; tier-6 phenomenal claim explicitly NOT made                                       | (a) keep the Level 0–4 ladder as a result; (b) drop interiority vocabulary entirely  | `phenomenal_consciousness_claim: not_claimed` already holds; the ladder is archived/non-authoritative and reviewer-hostile as a result. Retaining operational interiority vocabulary (scars/affect/self-model) is honest and is our differentiator, provided it names measurable variables, not experiences.                                                                                                            |
| DL-14 | Foundation `memory.py` reuse          | Use its SQLite/FTS5 store as the Retrieval baseline backend; add cosine over the stored embeddings | build a new vector store                                                             | The store already exists with hard-erasure receipts and is dependency-free; audit found only the similarity search unimplemented (embeddings are already stored). Minimal, fair, and avoids a new dependency.                                                                                                                                                                                                           |
| DL-15 | Package location & posture            | `docs/research/neurips-2026-workshop/`, planning-only, nothing authorized                          | put specs under `docs/superpowers/specs/`                                            | Keeps the research program together and separate from feature specs; every doc reaffirms planning-only / `not_authorized` / `training_weight: 0.0`.                                                                                                                                                                                                                                                                     |
