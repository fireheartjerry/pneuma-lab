# Pneuma Voice-v0 — Phase C Implementation Plan (HTML mind monitor)

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development or superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Generate a self-contained, byte-deterministic HTML "mind monitor" from the voice stream — a shareable page that plays the thought stream tick-by-tick, colour-codes each line by credit, reveals receipts on click, and shows the evidence badge + per-family status.

**Architecture:** `monitor.py` builds a deterministic payload from a stream dict (atoms + rendered + sidecar), injects it into a single self-contained HTML document (inline CSS + JS, no external requests — CSP-safe), and writes `monitor.html`. The page renders entirely from the embedded JSON. The generator is pure and deterministic; runtime reveal animation does not affect the file bytes.

**Tech stack:** Python stdlib (`json`) + pytest for the generator; vanilla inline HTML/CSS/JS for the page (no framework, no CDN, system font stack).

**Prereq:** Phases A + B committed (`voice_run`/`voice_run_paired` return the stream dict with `atoms`, `rendered`, `sidecar`).

"""Self-contained HTML "mind monitor" generated from a voice stream.

Pure and byte-deterministic: it injects a sorted-key JSON island into one inline
HTML/CSS/JS document (no external requests — safe to share and CSP-compatible).
The page renders the thought stream tick-by-tick from the embedded data; the
runtime reveal animation does not affect the generated bytes.
"""

from __future__ import annotations

import json
from pathlib import Path


def monitor_payload(stream: dict) -> dict:
    """Deterministic view model: per-tick rendered lines with credit + receipts."""
    by_tick: dict[int, list[dict]] = {}
    for atom, rendered in zip(stream["atoms"], stream["rendered"]):
        by_tick.setdefault(int(atom["tick"]), []).append(
            {
                "type": atom["type"],
                "credit_status": atom["credit_status"],
                "text": rendered.get("text_voiced") or rendered["text_deterministic"],
                "voice_status": rendered.get("voice_status", "deterministic_only"),
                "receipts": atom.get("receipts", []),
            }
        )
    ticks = [{"tick": t, "lines": by_tick[t]} for t in sorted(by_tick)]
    sidecar = stream.get("sidecar", {})
    return {
        "subject": stream["subject"],
        "mode": stream["mode"],
        "evidence_level": stream["evidence_level"],
        "run_id": stream["run_id"],
        "indicator_family_status": sidecar.get("indicator_family_status", {}),
        "ticks": ticks,
    }

        });
        el.appendChild(tog); el.appendChild(box);
      }
      sec.appendChild(el);
    });
    stream.appendChild(sec);
  });
  var sections = Array.prototype.slice.call(document.querySelectorAll(".tick"));
  function showAll(){ sections.forEach(function(s){ s.classList.add("show"); }); }
  function play(){
    sections.forEach(function(s){ s.classList.remove("show"); });
    var i = 0;
    (function step(){
      if(i >= sections.length) return;
      sections[i].classList.add("show");
      sections[i].scrollIntoView({behavior:"smooth", block:"center"});
      i++; setTimeout(step, 900);
    })();
  }
  document.getElementById("all").addEventListener("click", showAll);
  document.getElementById("play").addEventListener("click", play);
  showAll();
})();
</script>
</body>

def render_html(stream: dict) -> str:
    """Render a self-contained, deterministic mind-monitor HTML document."""
    payload = monitor_payload(stream)
    data = json.dumps(payload, sort_keys=True, ensure_ascii=False)
    # Neutralize any </script> in data so it can't break out of the JSON island.
    data = data.replace("</", "<\\/")
    subject = str(stream["subject"])
    return _TEMPLATE.replace("__DATA__", data).replace("__SUBJECT__", subject)


def write_monitor(stream: dict, out_path: str | Path) -> None:
    """Write the mind-monitor HTML to ``out_path`` (deterministic)."""
    p = Path(out_path)
    p.parent.mkdir(parents=True, exist_ok=True)
    p.write_text(render_html(stream), encoding="utf-8", newline="\n")


__all__ = ["monitor_payload", "render_html", "write_monitor"]
